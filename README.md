# Formula Desk

A compact Next.js math utility with deterministic word-problem solvers, calculator, unit converter, formula search, local favorites/history, and persistent theme.

## Run
```bash
npm install
npm run dev
```

## Deploy
Import the repository into Vercel as a Next.js project.

Note: This packaged build contains a curated starter formula library and an extensible data schema. It does not falsely pad the library to 500 entries with duplicate placeholder formulas.
